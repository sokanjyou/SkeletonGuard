单目 3D 环境协同跌倒检测算法
================================

一、算法名称
------------

SSKF-TopoFall: Subspace Sparse Kalman Fusion with Environmental Topology for Monocular 3D Fall Detection

目标：用单目摄像头检测老人跌倒，同时降低“在榻榻米、地毯、矮床、沙发上正常休息”被误判为跌倒的概率。


二、总体流程图
--------------

```mermaid
flowchart TD
    A[单目视频流] --> B[YOLO26-Pose 2D 姿态检测]
    B --> C[2D 关键点流 K2D: x,y,c]
    C --> D[坐标归一化与低置信关键点修复]
    D --> E[子空间稀疏 2D-to-3D 升维]
    E --> F[人体骨长/关节合法边界投影]
    F --> G[矩阵级 Kalman 时序融合]
    G --> H[平滑 3D 骨架与速度估计]

    A --> I[环境语义拓扑图]
    I --> J[床/榻榻米/地毯/地面/浴室等区域]
    C --> K[人体接触点估计: 脚踝/框底/骨盆]
    H --> L[姿态、重心高度、下坠速度特征]
    J --> M[人体-环境拓扑关系]
    K --> M
    L --> N[原始跌倒分数]
    M --> O[语义风险增强/休息场景抑制]
    N --> P[最终跌倒分数]
    O --> P
    P --> Q{超过阈值并持续?}
    Q -->|是| R[跌倒告警]
    Q -->|否| S[正常/休息/待观察]
```


三、核心数据结构
----------------

YOLO26-Pose 输出每帧人体关键点：

K_t^{2D} = {(u_i, v_i, c_i)}_{i=1}^{17}

其中 u_i, v_i 是像素坐标，c_i 是关键点置信度。代码里对应：

- src/models/yolo26_pose.py: YOLOPoseEstimator
- src/models/yolo26_pose.py: PoseDetection


四、子空间稀疏 2D-to-3D 升维
----------------------------

1. 3D 姿态表示

把 17 个 3D 关节展平成向量：

X_t in R^{51}

用人体姿态均值 mu 与低维姿态字典 B 表示：

X_t = mu + B alpha_t

其中 B in R^{51 x d}，alpha_t 是稀疏系数。稀疏性迫使姿态只落在人类解剖上常见的低维动作子空间内，减少单目深度歧义。

2. 优化目标函数

每帧求解：

alpha_t^* =
argmin_alpha
|| W_t (Pi(mu + B alpha) - K_t^{2D}) ||_2^2
+ lambda ||alpha||_1
+ beta sum_{(i,j) in E} ( ||X_i - X_j||_2 - l_{ij} )^2
+ gamma || Z_t - Z_{t-1} ||_2^2

含义：

- Pi(.)：弱透视投影，取 3D 骨架的 x,y 到归一化 2D 平面。
- W_t = diag(c_i)：关键点置信度权重，YOLO 不确定的点对升维影响更小。
- ||alpha||_1：子空间稀疏约束。
- E：人体骨架边集合。
- l_{ij}：标准人体骨长或个人标定骨长。
- gamma ||Z_t - Z_{t-1}||_2^2：深度轴连续性，抑制 Z 轴跳变。

3. 工程实现

代码使用近端梯度下降：

alpha <- SoftThreshold(alpha - eta grad_alpha, eta lambda)

并在每轮后做骨长投影：

X_i, X_j <- center +/- 0.5 l_{ij} (X_i - X_j) / ||X_i - X_j||

对应代码：

- src/models/lifter_3d.py: SubspaceSparseLifter
- src/models/lifter_3d.py: LifterConfig


五、Kalman 矩阵级时序融合
-------------------------

1. 状态向量

对 17 个关节同时建模位置和速度：

s_t = [ vec(X_t), vec(V_t) ]^T in R^{102}

2. 状态转移

s_t = F s_{t-1} + q_t

F =
[ I  dt I
  0   I  ]

观测模型：

z_t = H s_t + r_t

H = [ I  0 ]

3. 标准更新公式

预测：

s_{t|t-1} = F s_{t-1|t-1}

P_{t|t-1} = F P_{t-1|t-1} F^T + Q

更新：

K_t = P_{t|t-1} H^T (H P_{t|t-1} H^T + R_t)^{-1}

s_{t|t} = s_{t|t-1} + K_t (z_t - H s_{t|t-1})

P_{t|t} = (I - K_t H) P_{t|t-1}

4. 关键融合点

R_t 不是固定常数，而是由 YOLO26-Pose 的关键点置信度控制：

R_t = diag( sigma_r^2 / max(c_i, epsilon) )

置信度低的关节测量噪声更大，Kalman 会更相信运动预测；置信度高时更相信当前观测。

对应代码：

- src/models/kalman_fusion.py: SkeletonKalmanFilter


六、环境语义拓扑协同
--------------------

仅看骨架会把“老人躺在榻榻米/地毯/矮床上休息”误判为跌倒。为解决这个盲区，引入环境语义图 G_env：

G_env = (V_s, E_s)

V_s 是区域节点，例如 floor、tatami、bed、carpet、bathroom。每个区域包含：

- polygon：图像中的语义区域多边形。
- height_m：该表面的物理高度。
- rest_allowed：该区域是否允许正常躺卧休息。
- fall_risk：该区域是否属于高风险区域。

人体与环境之间建立拓扑关系：

T_t = phi(contact_point_t, zone_t, posture_t, height_t)

接触点优先用脚踝，脚踝不可见时退化为人体框底部。然后判断接触点落在哪个语义区域。

环境修正因子：

f_env =
clip(
1
- a * I(rest_allowed and contact_score > tau_c and impact_score < tau_v)
+ b * I(high_risk_zone)
+ c * topology_score,
f_min, f_max
)

最终分数：

S_final = clip(S_raw * f_env, 0, 1)

这条规则的关键是：休息场景只在“允许休息区域 + 接触稳定 + 没有明显下坠冲击”时抑制告警；如果出现明显冲击或高风险区域，仍会保持或增强告警。

对应代码：

- config/zones_config.json
- src/pipeline/environment_context.py: RegionSemanticMap
- src/pipeline/fall_detector.py: FallDetector


七、跌倒判定公式
----------------

从平滑后的 3D 骨架提取三个核心特征：

1. 躯干水平化程度

shoulder = (X_5 + X_6) / 2
hip = (X_11 + X_12) / 2
torso = shoulder - hip

P_posture = ||torso_{x,z}||_2 / (||torso_{x,z}||_2 + |torso_y| + epsilon)

2. 身体垂直跨度压缩程度

单目未做完整相机标定时，3D 骨架采用骨盆 root-centered 坐标，不能直接把 hip_y 当作真实离地高度。因此工程实现使用 3D 垂直跨度：

span_y = max_i X_{i,y} - min_i X_{i,y}

P_height = clip(1 - span_y / H_upright, 0, 1)

如果部署时完成地面/床面相机标定，可替换为真实离地高度版本：

P_height_calibrated = clip(1 - (hip_y - h_surface) / h_low, 0, 1)

3. 下坠冲击

P_impact = clip(max(0, -v_hip_y) / v_fall, 0, 1)

原始跌倒分数：

S_raw = 0.42 P_posture + 0.28 P_impact + 0.30 P_height

最终判定：

Fall = I( mean_{k=t-w+1}^{t} S_final(k) >= tau )

使用滑动窗口均值而不是单帧阈值，可以降低坐下、弯腰、遮挡时的瞬时误报。


八、代码运行方式
----------------

安装依赖后运行摄像头：

python -m src.main --config config/config.yaml --source 0 --show

运行视频并保存结果：

python -m src.main --config config/config.yaml --source data/demo.mp4 --output data/out.mp4

注意：

1. 当前默认读取本地 YOLO26-Pose 权重 data/models/yolo26m-pose.pt。跌倒检测必须使用 pose 任务权重，因为系统依赖关键点输出。
2. config/zones_config.json 里的多边形需要根据真实摄像头画面标注。
3. 当前 3D 升维模块是可运行的算法骨架。生产级效果需要用 Human3.6M、MPI-INF-3DHP 或自采老人居家数据训练/替换姿态字典 B 或神经初始化器。
4. 如果摄像头固定，建议做一次地面/床面/榻榻米区域标定，环境语义对误报抑制会明显更稳。
